Project Proposal: Hotel Reservation System
--------------------------------
Project Title
English: Hotel Reservation System
Arabic: نظام إدار ة وحجز غرف الفنادق
--------------------------------
Abstract
The Hotel Reservation System is a Windows Forms application developed using C# to
improve the management of hotel room reservations in small hotels. Many hotels still 
rely on manual methods such as paper records or simple spreadsheets, which can lead to
booking errors, lost data, and difficulty tracking room availability. This project proposes
a simple software solution that organizes room information, customer data, and reservation details in a structured digital system.
The application allows staff to add rooms, register customers, create or cancel reservations, and
check available rooms through an easy‑to‑use interface. The system also calculates the total reservation 
cost based on the room type and number of booking days. Object‑oriented programming concepts such as classes,
inheritance, enumerations, and arrays of objects are used to model the system, while file handling is implemented to store and retrieve data.
--------------------------------
Problem Statement
Many small hotels rely on manual methods to track room availability and reservations. This can lead to errors such as double booking, lost records, and inefficient management of customer information. A simple software system can help automate these tasks and make reservation management faster and more reliable.
--------------------------------
Proposed Solution
The proposed solution is a Hotel Reservation System that provides a user‑friendly Windows Forms
interface for managing hotel operations. The system allows staff to manage rooms, customers,
and reservations in an organized way while automatically handling booking calculations and data storage.
--------------------------------
Project Objectives
Develop a functional hotel reservation management application.
Apply core Object‑Oriented Programming (OOP) concepts such as classes, inheritance, ,encapsulation and enumerations.
Design a user‑friendly interface using Windows Forms.
Implement file handling to store and retrieve reservation data.
Provide an organized way to manage rooms, customers, and reservations.
--------------------------------
Main System Features
Add and manage hotel rooms.
Register customer information.
Create and cancel reservations.
Display available and reserved rooms.
Automatically calculate reservation cost based on the number of days.
Save and load data using files.
